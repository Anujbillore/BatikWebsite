Create a bright, vibrant 3D website for a family business showcasing Batik Craft (Ujjain) and Smoking Craft (Mhow).

### Website Requirements:
- Sections:
  - Home → Hero banner with 3D animation of Batik patterns + smoking craft visuals
  - Collections → Showcase Batik fabrics, Smoking craft items with interactive 3D gallery
  - About Us → Family heritage, craft history, location highlights (Ujjain & Mhow)
  - Contact → Phone number, WhatsApp integration, Instagram feed, inquiry form
- 3D interactive elements:
  - Rotating Batik fabric patterns with glowing textures
  - Smoking craft items displayed in 3D carousel
  - Scroll-driven storytelling with smooth 3D transitions
- Color palette: Bright tones (turquoise, saffron, gold, ivory, sky blue) with neon accents
- Style: Vibrant, festive, heritage-inspired yet modern
- Typography: Elegant serif for heritage + bold futuristic fonts for headings
- Call-to-action: “Experience Craft. Connect With Us.”

### Integrations:
- **Contact Form:**
  - Fields: Name, Email, Phone, Message
  - On submit → Send notification to registered phone number via Twilio API
  - WhatsApp Business API → Auto-confirmation message
- **Instagram Integration:**
  - Embed Instagram feed using Graph API
  - Animated “Follow Us” button
- **WhatsApp Integration:**
  - Floating WhatsApp chat button for instant inquiries

### Technology Stack:
- **Frontend:** React.js + Next.js
- **3D & Animations:** Three.js + WebGL + GSAP
- **UI Library:** TailwindCSS (responsive, modern design)
- **Backend:** Node.js + Express
- **Database:** MongoDB (for form submissions)
- **Deployment:** Vercel (frontend) + AWS/Azure (backend)
- **Performance:** WebGPU fallback to WebGL for smooth rendering
- **Latest UI Trends:** Bright color gradients, Glassmorphism, Dark Mode optional, Micro-interactions

### Output:
- Generate a bright, vibrant 3D website mockup (React + Three.js/WebGL)
- Include working form with Twilio + WhatsApp API integration
- Embed Instagram feed
- Provide ad campaign visuals (image/GIF/video concepts) for Batik & Smoking crafts
- Keep tone professional yet engaging
